VanillaCord

Patch vanilla Minecraft server JARs so they can safely sit behind BungeeCord, BungeeGuard, or Velocity proxies with forwarded player identity.

SupraCraft-maintained fork. This repository is derived from ME1312/VanillaCord. Upstream authorship and license history are preserved; new SupraCraft artifacts use SupraCraft-owned identity and provenance.

What it does

Vanilla backends
Downloads Mojang server JARs and writes patched servers under out/<version>.jar.
Proxy forwarding
Supports Velocity modern forwarding and the historical BungeeCord/BungeeGuard paths.
Validated artifacts
Builds verify reproducibility, artifact identity, provenance, and compatibility boundaries.

Quick start

Download an exact release from GitHub Releases and run:

java -jar supracraft-vanillacord-<version>.jar <minecraft-versions...>

The patcher itself emits Java 21 bytecode. The Java runtime required by a patched server is determined by the selected Minecraft release.

Scope and safety

VanillaCord is specifically for vanilla Minecraft backend servers. Servers with their own native proxy-forwarding support are outside this repository’s scope. Forwarding protects proxy-supplied identity data, but backend server ports should still be firewalled so clients cannot bypass the proxy.

Related project

The patcher consumes SupraCraft Bridge as an independently versioned bytecode transformation dependency. Release builds record the exact immutable Bridge coordinate they used.
