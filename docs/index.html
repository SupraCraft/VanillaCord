What it does

Start vanilla

VanillaCord works with Mojang vanilla server JARs rather than replacing them with a server fork.

Add forwarding

The patcher adds the forwarding behavior needed behind supported proxy configurations.

Check compatibility

CI probes current and requested Minecraft versions using documented blocking and advisory tiers.

Quick start

Download an exact release and run:

java -jar supracraft-vanillacord-<version>.jar <minecraft-versions...>

Compatibility guide · Recorded compatibility report · Diagnostics

Keep the backend private

Forwarding protects proxy-supplied identity data, but backend server ports should still be firewalled so clients cannot bypass the proxy. Servers with their own native forwarding support are outside VanillaCord’s intended scope.
