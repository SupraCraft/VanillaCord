VanillaCord

Connect vanilla Minecraft servers to proxy networks. VanillaCord patches Mojang server JARs so plain backends can use forwarded player identity from Velocity, BungeeCord, or BungeeGuard.

How it fits

Start plain

Choose the Mojang server versions you need. VanillaCord downloads the corresponding vanilla server JARs.

Patch them

Run VanillaCord once for those versions. Patched server JARs are written under out/.

Put them behind the proxy

Use the forwarding mode that matches your proxy and keep the backend network boundary closed to direct clients.

Quick start

Download an exact release, then run:

java -jar supracraft-vanillacord-<version>.jar <minecraft-versions...>

Minecraft releases can require different Java runtimes after patching. Use the compatibility documentation for the selected server version rather than assuming the patcher’s Java 21 runtime applies to every patched server.

Keep backend ports private. Forwarded identity is intended to arrive through the proxy. Firewall backend server ports so players cannot bypass that boundary and connect directly.

Compatibility is measured, not guessed

Current stable compatibility is a blocking validation target; development and best-effort legacy probes are advisory. See the latest recorded report, operations guide, and strategy.
