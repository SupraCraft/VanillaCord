What VanillaCord does

VanillaCord downloads the Mojang server JAR for the Minecraft version you select, patches it for proxy forwarding, and writes the patched server under out/. It is intended for vanilla backend servers; servers with their own forwarding implementation should use that implementation instead.

Release confidence

Stable releases are built reproducibly, record the exact Bridge dependency, and must pass the declared Minecraft support matrix before publication. Each supported Minecraft generation is patched, its output JAR is checked, and the patched server is boot-smoked on the target Java runtime.
